# Frozen chronological THEIA explanation comparison

These are actual executions on the two frozen catalogs exported by the chronological THEIA producer. `earliest_alerts` and `temporal_delta` each contain 32 conditional cases. They share 18 current events: 64 catalog cases represent 46 unique current events from seven processes, not 64 independent alerts. The same source engagement was used previously in static analyses; this is newly chronological validation, not a previously unseen dataset.

TracePolicy, KernelSHAP, LIME and the exact complete-core FFA membership adaptation each have 64 outputs. Native Alibi Anchors has 192 outputs (seeds 11, 23, 47 per case). All 448 outputs are sufficient and inclusion-minimal under the full shared intervention domain; none failed or timed out. Every returned release witness was independently rechecked. Independent truth tables and full minimal-core families agree across the two NumPy environments.

Every case has one minimal core containing the current event and `D_UNSEEN`, of size two. Most domains contain two actual consecutive process events and all seven frozen rules (nine units); two cases per cohort have only one event (eight units). Temporal history changes which observations fall through the learned allow rules, but these positive-retention cores do not demonstrate predecessor necessity. The fixed diagnostic EXECUTE-to-CONNECT policy fired zero test sequences; it was not retuned or represented as observed evidence.

`comparative_summary.json` reports results separately by cohort, including total timings. Import costs are recorded separately in method manifests. Baseline totals include native attribution or Anchor selection and exact fixed-set sufficiency/minimality witnesses. FFA totals include full-table enumeration, complete-core calculation, membership weighting, prefix selection and proof; its cached state enumeration backend differs from the TracePolicy extractor. Timings are descriptive on these conditional cohorts and do not establish general algorithmic superiority. Successful explanation fidelity does not establish detector accuracy; consult the producer's separately reported detection results, including false positives.

Each cohort contains method JSON/CSV, seed/package/input manifests, and `oracle_tables/case_XXX.npz` with integer-mask labels, exact unit order and all minimal-core masks. No historical Docker outputs were overwritten.

Reproduce main methods in the main environment and native Anchors in its separate Alibi environment, using `experiments/revision_catalog_methods.py --case-catalog <frozen catalog> --output <new cohort directory> --methods tracepolicy,kernelshap,lime,ffa`, then `--methods anchors --seeds 11,23,47`. Generate the independently verified comparison with `experiments/revision_catalog_summary.py --root <campaign directory>`.
